# 一页 · 中文 TXT 阅读器

面向对象程序设计课程 Demo。原生 HTML、CSS、JavaScript 实现；书籍保存在本机浏览器。支持多书书架、UTF-8 / GB18030、滚动阅读、字号、浅色和深色主题，以及每本书独立的阅读位置。

## 打开程序

当前电脑已检测到 Node.js 和 Python。最方便的方法：双击项目中的 **启动阅读器.cmd**，等待浏览器打开。保持出现的终端窗口运行，阅读结束后在终端按 `Ctrl+C` 停止，再关闭窗口。

也可以在本项目文件夹打开 PowerShell，输入：

```powershell
npm start
```

浏览器访问：<http://127.0.0.1:8000/>。运行 Demo 无需 `npm install`；启动服务只使用 Node.js 内置模块。

若电脑没有 Node.js，但有 Python，可以改用下面的命令，随后访问相同地址：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

两种服务只需运行一个。端口被占用时，先检查已有页面和终端；关闭旧服务后再启动。阅读器通过本地 HTTP 服务打开，JavaScript 模块由浏览器加载。

## 五分钟动手测试

1. 打开页面，保持默认 UTF-8，点击“导入 TXT”，选择 `samples/河边散记-UTF8.txt`。应显示正常中文，左侧出现一本书。
2. 向下滚动，等待底部显示“已保存”。在阅读区域顶部调整字号、切换深色主题；这组按钮会随阅读保持可见。
3. 将编码改为 GB18030，导入 `samples/山间来信-GB18030.txt`，滚动到另一位置。
4. 点击左侧第一本书，再点击第二本书，两本书应分别回到各自的位置。
5. 等待“已保存”或“阅读设置已保存”，刷新页面，再关闭标签页并重新访问相同地址；应保留书架、最近一本书、字号、主题和阅读位置。
6. 点击一本书的“删除”，先取消一次，再确认一次；只有确认后才从书架消失，原始 TXT 文件保留。

乱码时切换编码并重新导入原 TXT。错误编码导入形成的条目可手动删除。书名相同的导入会作为两本独立书籍保留。

## 代码怎样对应面向对象知识

- `Book`：一本具体的书；属性记录书名、段落和位置，方法约束位置范围。
- `TxtImporter`：负责把文件变成书籍对象，集中处理编码与格式检查。
- `LibraryStore`：负责数据库读写，封装 IndexedDB 的事务细节。
- `ReaderSettings`：管理字号、主题和设置持久化。
- `ReaderView`：负责显示内容、书架和状态，以及获取与恢复阅读位置。
- `ReaderApp`：组合上述对象，协调用户操作。`main.js` 创建应用对象并启动。

建议先看 `Book.js`，再沿着 `ReaderApp` 的导入流程看对象如何协作。课程讲解重点是类与实例、属性与方法、封装和组合。所有正文通过纯文本方式显示。

完整功能与设计见 [开发文档](开发文档.md)。

## 自动化测试

需要 Node.js 20 或更新版本；浏览器测试使用本机安装的 Chrome 和 Edge。首次准备测试依赖：

```powershell
npm ci
```

执行：

```powershell
npm test
npm run test:browser
```

浏览器测试使用独立的临时浏览器环境，不修改日常浏览器书架；必要时自动启动本地服务。测试截图输出到 `test-results`，该目录不进入 Git。

2026-11-10 实测结果：5 项核心测试、8 项浏览器测试全部通过。浏览器版本：Chrome 156.0.8078.80、Edge 157.0.4341.42（自动化无界面运行）。验证了多书独立位置、刷新和关闭标签页恢复、删除确认、纯文本安全显示、GB18030、同名文件、空文件、字号上下限、主题持久化、键盘 Enter 操作、窗口重排、存储失败及重试、损坏设置回退。页面浅色与深色截图已检查；未测试其他浏览器、系统重启恢复或真实磁盘耗尽。

## 使用范围与已知限制

- 单本原始 TXT 上限 5 MiB；超长文本使用完整 DOM 渲染，未进行大规模性能测试。
- 数据属于当前浏览器和当前地址。固定使用 `http://127.0.0.1:8000/`；更换端口或浏览器会使用另一份数据。
- 清除网站数据或浏览器回收存储可能删除书架，请保留原 TXT。隐私模式不适合长期保存。
- 推荐一个标签页使用阅读器；多标签页同时修改同一本书时，最终以最后写入的位置为准。
- 滚动每约 500 ms 保存，立即强制关闭可能丢失最后一小段位置。字号和窗口变化后允许少量定位误差。
- 不含云同步、章节识别、搜索、批注或 PDF / EPUB 支持。
